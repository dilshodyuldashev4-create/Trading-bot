# Gold Signals Bot (XAUUSD)

Telegram-бот сигналов по золоту: проверяет рынок каждые 15 секунд, сам рассылает сигналы
с картинкой (вход, Stop Loss, Take Profit), даёт 3 дня бесплатно, потом продаёт подписку
через Telegram Stars. Есть админ-панель, разбор фундаментальных новостей и календарь событий США.

## Кнопки бота

| Кнопка | Что делает | Доступ |
|---|---|---|
| 📊 Сигнал | Анализ рынка: ожидаемый сетап и уровни. Подтверждённые сигналы приходят автоматически | 3 дня бесплатно, потом подписка |
| 📰 Фундаментальные новости | Свежие новости коротко: как влияют на золото и доллар | бесплатно |
| 🗓 Календарь новостей | CPI, NFP, FOMC и др.: время, прогноз/факт, влияние. 3 дня вперёд и 3 назад | бесплатно |
| 💎 Подписка | Оплата в Telegram Stars | — |

**Авторассылка всем участникам:** итог каждого сигнала (TP или SL) с картинкой и статистикой; за 15 минут до важной новости США — прогноз и чем она грозит золоту; после выхода — факт, прогноз, предыдущее значение и влияние на золото и доллар (факт ищется через Claude с веб-поиском, нужен `ANTHROPIC_API_KEY`).

Админ: `/admin` (статистика, рассылка, выгрузка подписчиков, последние сигналы), `/grant <id> <дней>`, `/revoke <id>`, `/close <номер> tp|sl` (закрыть сигнал вручную, всем уходит сообщение о тейке/стопе).

## 🤖 Автоторговля на счетах подписчиков (MetaTrader 4/5)

Подписчик нажимает **🤖 Автоторговля** (или отвечает «Да» на вопрос сразу после выбора капитала), выбирает
платформу и брокера из списка (Exness, XM, RoboForex, Alpari, FBS, IC Markets и др. или «Другой брокер» — любой,
A-book или B-book), нажимает свой сервер и отправляет номер счёта и пароль. Бот сам подключается к счёту через
[MetaApi](https://metaapi.cloud) и дальше по каждому сигналу:

* открывает сделку по рынку, лот — по реальным средствам на счёте (`AUTOTRADE_RISK_PCT`, не больше `AUTOTRADE_MAX_LOT`);
* сразу ставит у брокера **Stop Loss и Take Profit** от цены брокера (котировки бота и брокера отличаются на пару долларов,
  поэтому расстояние до SL/TP то же, что в сигнале, а уровни — от цены входа у брокера);
* закрывает сделку, когда сигнал закрывается в боте (TP/SL, перед новостью, `/close`, «Отклонить»), если брокер не закрыл её сам;
* пишет подписчику, что открыл и с каким результатом закрыл.

Пароль уходит только в MetaApi; в базе бота хранится id счёта в MetaApi, номер счёта и сервер. Сообщение с паролем
бот сразу удаляет из чата. «🗑 Отключить счёт» удаляет счёт и пароль из MetaApi.

**Настройка:** зарегистрируйтесь на [app.metaapi.cloud](https://app.metaapi.cloud), возьмите токен
([app.metaapi.cloud/token](https://app.metaapi.cloud/token)) и впишите в `.env` `METAAPI_TOKEN=...`, затем
`docker compose up -d --build`. MetaApi платный за каждый подключённый счёт (есть бесплатный лимит для тестов).
По умолчанию `AUTOTRADE_DEMO_ONLY=1` — подключаются только демо-счета; когда проверите, поставьте `0`.

Админ: `/autotrade off` — остановить открытие новых сделок у всех, `/autotrade on` — включить,
`/autotrade invite` — задать вопрос про автоторговлю всем активным подписчикам, кого ещё не спрашивали.

## Стратегия и бэктест

В бот поставлена связка **ICT Silver Bullet + пробой азиатского диапазона** (M15, SL 100 / TP 200 пипсов).
На реальных свечах XAUUSD (декабрь 2023 – август 2026): 632 сделки, винрейт 36.6%, +6100 пипсов.
При риске 1:2 безубыточность — 33.3%. Ни одна проверенная стратегия не дала 60% при 1:2;
полная таблица — [reports/backtest.md](reports/backtest.md).

Повторить бэктест: `python scripts/run_backtest.py`.

## Запуск 24/7 на сервере (VPS)

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Получите ключ котировок: [Twelve Data](https://twelvedata.com) (для опроса раз в 15 секунд нужен платный тариф)
   или бесплатный демо-счёт OANDA (`DATA_PROVIDER=oanda`).
3. По желанию — ключ [Anthropic API](https://console.anthropic.com) для кратких разборов новостей.
4. На сервере с Docker:

```bash
git clone https://github.com/dilshodyuldashev4-create/Trading-bot.git && cd Trading-bot
cp .env.example .env   # заполните BOT_TOKEN, ADMIN_IDS, ключ котировок
docker compose up -d --build
docker compose logs -f
```

`restart: always` перезапускает бота при ошибке и после перезагрузки сервера.

Без Docker: `pip install -r requirements.txt && python -m goldbot`.

## Структура

* `goldbot/backtest.py`, `scripts/run_backtest.py` — бэктест с фиксированным SL/TP и спредом
* `goldbot/engine.py` — проверка рынка, создание и закрытие сигналов
* `goldbot/chart.py` — картинка сигнала
* `goldbot/bot.py` — Telegram-бот, подписка, админка
* `goldbot/news.py`, `goldbot/econ_calendar.py` — новости и календарь

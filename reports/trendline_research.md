# Стратегия трендовой линии: проверка на истории

Свечи XAUUSD M15 (MetaTrader 5) 01.12.2023 – 21.08.2026, спред учтён. Линии строит программа по точным
правилам, без заглядывания в будущее: восходящая линия — через два последних свинг-лоя (второй выше первого),
нисходящая — через два последних свинг-хая (второй ниже). Свинг — минимум/максимум, у которого N свечей слева
и справа выше/ниже; он становится известен только через N свечей. Линия живёт ограниченное время после
второго свинга и умирает после первого закрытия за ней.

* **Пробой** — закрытие свечи за линией (как на скриншоте): восходящая пробита вниз → SELL, нисходящая вверх → BUY.
* **Отскок** — тень дошла до линии и свеча закрылась с правильной стороны → вход по направлению линии.

Сделка — как у бота: вход по открытию следующей свечи, стоп 2 ATR, тейк 3 ATR (1.5R), стоп и тейк в одной
свече — считаем стоп. R — результат в рисках. Параметры выбираем по первой половине (до 07.2025),
вторая половина — честная проверка. Повторить: `python scripts/trendline_research.py`.

## Главное

* **В боте сейчас такой стратегии нет, и добавлять её я не советую.** Пробой трендовой линии на золоте M15
  даёт маленький плюс, но слабее и нестабильнее любой из 5 текущих стратегий.
* **Пробой линии без фильтров (как на скриншоте)** — почти ноль: +14R за 1 233 сделки, +0.012R на сделку.
  В первой половине +40R, во второй −25R. То есть в последний год простой пробой линии терял деньги.
* **Лучший найденный вариант** (свинги по 3 свечи, вход только когда ADX < 25) — +0.058R на сделку,
  но в первой половине +44R, во второй уже +18R: преимущество тает. Соседние настройки дают от +62R до −26R,
  результат сильно зависит от мелких параметров — признак случайности, а не устойчивого преимущества.
* **Отскок от линии** — убыточен почти во всех вариантах (27 из 27 в минусе в первой половине).
* **Для сравнения**, с той же сделкой (стоп 2 ATR, тейк 3 ATR): squeeze +0.144R, amd +0.149R, fvg_m15 +0.092R,
  liq_m15 +0.073R на сделку.
* **Если всё-таки добавить в бота** лучший вариант: итог за 2.7 года +410R → +466R, но средняя сделка хуже
  (+0.114R → +0.096R), максимальная просадка больше (49R → 60R), убытков подряд больше (14 → 18).
  Для проп-счёта, где главное — не нарушить лимит просадки, это скорее вред, чем польза.
* Частично идея пробоя линии уже есть в боте: стратегия liq_m15 торгует проколы свингов, donchian и squeeze —
  пробои диапазона.
